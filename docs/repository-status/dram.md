# `src/dram.rs`：主存

## 功能与实现

使用清零的 `Vec<u8>` 表示一段连续的小端内存，默认起点为 `cfg::DRAM_BASE`。它可以把裸二进制镜像复制到内存起点，并通过 `MemDevice` 接入总线。

## 实现状态

已经支持基本读写、镜像大小检查、默认布局和运行时 `base/size` 布局，也可以在指定地址装载字节或清零一段范围。单元测试覆盖 1、2、4 字节读写、越界和文件加载。地址低于基址或访问超出末端时会返回访问错误。

## 公共接口

- `Dram { pub dram: Vec<u8>, pub base: u64 }`
- `Dram::{new, with_layout, end, load, load_bytes, zero_range}`
- `Default` 和 `MemDevice` 实现

## 依赖关系

默认容量和基址来自 `cfg`，错误类型为 `trap::Exception`。命令行程序通过 `Platform` 创建并挂载 DRAM；测试平台没有复用该类型，而是维护自己的 RAM 向量。

## 已知问题与改进建议

- `read/write` 接受任意 `size`。读取超过 8 字节或写入超过 4 字节时，移位溢出可能使进程异常退出；`offset + size` 也没有检查整数溢出。
- 访存代码把 `u64` 地址差直接转为 `usize`；在地址空间较小的宿主机或极端自定义布局下可能截断。
- 公开底层 `Vec` 和 `base`，无法保持不变量。
- DRAM 只负责装载和清零指定范围，镜像格式解析由 `loader` 完成。
- 默认实例仍分配 128 MiB；可配置布局仍是连续 `Vec`，没有稀疏内存、快照或共享页机制。
- 建议限制访问宽度，使用切片完成安全的字节转换，并隐藏底层字段。
