# `tests/cli.rs`：命令行进程测试

测试通过 Cargo 提供的 `CARGO_BIN_EXE_arvsim` 启动编译后的命令行程序。目前有 3 个默认用例，检查帮助输出、原始二进制镜像运行到步数上限，以及镜像不存在时返回非零退出码。

测试检查程序的退出码、标准输出和标准错误输出。临时文件保存在 `CARGO_TARGET_TMPDIR`，文件名包含进程号，测试结束后删除。因测试失败而残留的文件也会随 `cargo clean` 清理。

本文件不提供库接口。测试使用 Rust 标准库的 `Command` 和 Cargo 临时目录；测试镜像包含一条 `addi x31, x0, 42`，运行时通过 `--max-steps 1` 停止。

目前还没有通过独立进程测试 ELF 镜像、全部参数错误、调试输出、UART 平台、地址重叠，以及为后续功能预留的执行错误退出情况。
