# `tests/cli.rs`：命令行进程测试

## 功能与实现

测试通过 Cargo 提供的 `CARGO_BIN_EXE_arvsim` 启动真正的命令行程序，检查帮助输出、裸二进制镜像运行到步数上限，以及镜像缺失时是否返回非零状态。临时文件位于 `CARGO_TARGET_TMPDIR`，文件名包含进程号，测试结束后会删除，异常残留也会随 `cargo clean` 清理。

## 实现状态

共有 3 个默认执行的进程测试，覆盖最基本的退出码以及标准输出和标准错误输出。

## 接口与依赖

本文件不提供库接口。测试依赖编译后的 `arvsim` 程序、标准库 `Command` 和 Cargo 目标临时目录。裸二进制镜像只包含一条 `addi x31, x0, 42`，并用 `--max-steps 1` 停止。

## 尚未覆盖

还没有以进程方式测试 ELF、完整的参数错误、调试输出、UART 平台、地址重叠和为未来保留的致命 CPU 错误退出路径。
