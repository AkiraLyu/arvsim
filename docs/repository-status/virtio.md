# `src/virtio.rs`：Virtio MMIO 块设备

模块依据 [Virtio 1.2](https://docs.oasis-open.org/virtio/virtio/v1.2/virtio-v1.2.html) 实现现代 MMIO 接口、64 位功能协商、磁盘读写、请求完成通知、中断确认和复位。

目前只有一个 split virtqueue：描述符表、可用请求和已完成请求分别存放。描述符记录设备需要访问的内存地址、长度和读写方向；设备把完成信息写入 used ring。

## 请求处理

- 检查队列配置、描述符编号和标志、描述符链是否成环、读写方向及磁盘扇区范围。
- 请求头可以分散在多个描述符中。数据也可以与请求头或状态字节共用一个描述符，不要求字段边界与描述符边界重合。
- 写入前检查全部数据区、状态字节和 used ring 完成记录的地址范围。传输缓冲固定为 64 KiB，不按被模拟程序提供的长度分配大缓冲。
- `used.len` 表示从设备可写区域起点开始、保证已经连续写入的字节数，可以小于实际写入量。部分读盘失败时，有效数据与末尾状态字节之间可能还有未写入区域，此时不能把状态字节加到这个长度中。
- 完成请求时只更新规范定义的状态和 used ring，不修改 xv6 驱动的内部字段。

设备始终提供 `VIRTIO_F_VERSION_1`，并拒绝驱动选择设备没有提供的功能。当前允许驱动不接受 VERSION_1 时继续运行，以兼容固定版本的 xv6 驱动；规范允许这种处理方式。

## 内存与存储接口

`GuestMemory` 提供 `validate_read/validate_write` 检查和 DMA 读写。检查方法只验证范围，不实际读写内存；单次读写失败不能留下部分写入。库中的实现是 `Shared<Dram>`。

`BlockBackend` 提供磁盘容量、只读属性和指定位置的读写。`MemoryBlockBackend` 把磁盘内容保存在内存中，替换内容时要求容量不变。

## 测试与限制

测试覆盖正常完成、字段跨越或共用描述符、DMA 和完成信息的范围检查、读盘失败后报告的长度，以及中断和复位。故障测试通过不可读扇区触发错误，再核对报告长度内的每个字节是否经过 DMA 写入，不限定后端调用次数或每次传输大小。

当前不支持 packed ring、间接描述符、EVENT_IDX、多队列、discard、write-zeroes、以文件保存磁盘数据或异步 I/O。队列通知会同步处理请求；找不到有效的完成信息写入位置时，设置 `DEVICE_NEEDS_RESET`，要求驱动复位设备。
