# `src/uart.rs`：简化 UART

## 功能与实现

实现 16550 UART 的最小输出功能：写 THR（偏移 `0x00`）时，把最低字节打印到宿主标准输出并立即刷新；读 RBR 始终返回 0；读 LSR（偏移 `0x05`）始终返回发送空闲位 `0x20`。

## 实现状态

部分实现，足以输出字符但无法输入、配置波特率或产生中断。单元测试覆盖固定 RBR/LSR 值和 THR 写成功。

## 公共接口

- `Uart { pub base: u64 }`
- `Uart::new(base)`
- `impl MemDevice for Uart`

## 依赖关系

该类型实现 `bus::MemDevice`，错误类型为 `trap::Exception`。命令行平台把它挂载到 UART MMIO 区域。xv6 测试没有复用库中的 UART，而是在 `TestBus` 中另行维护输入队列、输出缓冲和 PLIC 待处理位。

## 已知问题与改进建议

- 忽略访问宽度，未知寄存器错误地返回 `IllegalInstruction`。
- RV64 的 8 字节写会拆成两个 4 字节写。第一次写可能已经输出字符，第二次写却在偏移 4 失败，已发生的输出无法撤销。
- 没有接收功能、FIFO、IER/IIR 寄存器、中断请求（IRQ）或可替换的输入输出后端。
- 直接传入低于基址的地址时，`addr - base` 可能下溢；目前依赖 `Bus` 保证地址有效。
- 同步打印和刷新会直接影响宿主标准输出，也使输出难以测试。
- 建议把 UART 寄存器状态与宿主终端输出分开，复用测试 UART 的输入功能，并通过 PLIC 或其他中断控制器提交 IRQ。
