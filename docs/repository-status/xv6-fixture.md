# xv6 启动与功能测试

`src/xv6.rs` 提供 `Xv6Fixture::{new, from_env, directory, build}`，供 Cargo 示例和集成测试共同使用。运行需要内核 ELF 文件 `kernel/kernel` 和磁盘镜像 `fs.img`。内核由库中的 ELF 加载器直接写入平台内存，不再先加载到另一块临时 DRAM 中重复检查。

## 加速模式的要求

开启内核加速时，会检查 xv6 是否为固定提交、Git 跟踪的源码是否修改、构建记录是否一致，以及两个运行文件的 SHA-256 校验值，并读取所需内核符号。CPU 的配置接口负责检查加速配置中的地址和数据结构布局。

关闭加速后，只需两个运行镜像，不依赖 Git 仓库、符号工具或主机上单独保存的测试程序 ELF。

## 测试范围

默认测试调用实际的 `build` 方法，检查现有镜像能否创建机器。只有镜像目录不存在、且未设置 `ARVSIM_REQUIRE_XV6_FIXTURE` 时才跳过；目录已存在但必需文件缺失，或加速检查不通过时，测试会失败。

另有两个耗时较长的测试，通过 UART 输出检查 shell 能否执行基础程序，以及完整 usertests 能否通过。这两个测试标记为 `ignored`，需要单独运行。它们都包含启动过程，完整 usertests 也包含快速阶段，因此不再另设重复的启动和快速测试。

等待输出时发现失败标记会立即报错。最大步数只用于判断超时，不要求程序在固定周期数内完成。完整测试的快速阶段默认最多运行 6 亿步，慢速阶段为 20 亿步，可通过对应的 `ARVSIM_XV6_*_STEPS` 环境变量调整。命令和结果见 [验证记录](./verification.md)。
