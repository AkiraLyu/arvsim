# xv6 启动与验收

`src/xv6.rs` 提供 `Xv6Fixture::{new, from_env, directory, build}`，由 Cargo 示例和集成测试共用。运行只使用 `kernel/kernel` 与 `fs.img`，内核直接通过正式 ELF 装载器装入平台内存，无需另建临时 DRAM 重复验证。

开启内核加速时，另检查固定提交、已跟踪源码状态、构建记录和实际使用镜像的 SHA-256，并读取所需内核符号。加速配置的地址与布局由 CPU 配置入口统一检查。关闭加速后可直接使用打包的两个镜像，不依赖 Git 仓库、符号工具或测试程序 ELF。

默认测试调用实际 `build` 入口，确认现有镜像可组装机器。仅在目录完全不存在且未设置 `ARVSIM_REQUIRE_XV6_FIXTURE` 时跳过；缺失运行必需文件或加速记录不符会失败。

两个 `ignored` 用例通过 UART 验证：shell 执行基础程序，以及完整 usertests。启动已包含在两者中，完整 usertests 也包含快速阶段，因此不再重复运行独立启动和快速测试。等待期间发现失败标记立即报错；步数只作为超时预算，不断言固定周期数。

完整测试的快速阶段默认预算为 6 亿步，慢速阶段为 20 亿步，可用对应 `ARVSIM_XV6_*_STEPS` 环境变量覆盖。具体结果见 [验证记录](./verification.md)。
