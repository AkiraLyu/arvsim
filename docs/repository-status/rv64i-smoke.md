# RV64 程序与平台集成测试

`tests/rv64i_smoke.rs` 包含两个默认测试：

- 编译并运行一个 RV64 汇编程序，通过库中的加载器和平台检查内存读写、分支跳转、`x0` 保持为零，以及 `ebreak` 产生断点异常。
- 复位整机，检查 RAM 内容保留、UART 输入和输出状态清除。

单条 `addi`、UART 寄存器、Virtio 队列大小和总线访问宽度已经由对应模块的测试检查，集成测试不再重复这些用例。

编译工具通过 `Command` 直接启动，链接地址使用 `cfg::DRAM_BASE`，生成的文件保存在 Cargo 临时目录。测试需要 RISC-V GCC 和 objcopy，只检查所列程序和平台行为，不能证明整个指令集都符合规范。
