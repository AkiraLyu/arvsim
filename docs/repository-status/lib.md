# `src/lib.rs`：库边界

## 功能

声明并公开 crate 的十二个顶层模块，不做二次封装或预导出。

## 当前状态与实现思路

实现完成且极简：每个源文件直接成为公开模块。`clint`、`plic` 即使为空也被公开，因而公开 API 表达的能力大于实际能力。

## 对外接口

公开模块为 `bus`、`cfg`、`clint`、`cpu`、`csr`、`dram`、`instruction`、`loader`、`machine`、`plic`、`trap`、`uart`。

## 耦合方式

该文件没有运行时耦合；它决定下游可直接依赖所有实现细节，包括 `Cpu` 公共字段、CSR 常量和 `DeviceRegion`。

## 不完善之处

- 没有按“稳定公共 API”和“内部实现”区分可见性。
- 空模块被公开，容易使调用方误判平台支持程度。
- 已有简短 crate 级说明，但缺少可编译用法示例、稳定性边界和安全/兼容性约定。
