# 指令审查记录

2026-09-05 复核了 RV64I/M/A、现有 RVC、系统指令、对齐、LR/SC 和字节填充加速。

本轮让 LR/SC 查询实际内存页的保留版本，拒绝在默认 MMIO 上建立保留。普通 load/store 的重复分发已简化；字节填充模式要求有效指针、恒等 DRAM 映射和页内取指，并按单步预算分批执行。回归测试覆盖原有非法编码、访存事务宽度及新增 DMA 场景。

立即数测试改为实际执行指令，检查寄存器、栈访存和控制流，不再断言私有解码辅助函数或指令未使用的字段。字节循环测试执行完整客体循环，分别检查随指针变化的存储值和常量填充结果，不直接断言优化模式的识别结果。

当前同步单硬件线程模型没有并行重排，也没有 TLB；aq/rl 和 `sfence.vma` 的处理应结合这一模型理解。多硬件线程、完整 RVC 和通用符合性验证仍未完成，见 [指令状态](../docs/repository-status/instruction.md)与 [后续计划](../docs/repository-status/gaps-and-roadmap.md)。
