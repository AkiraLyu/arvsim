# 构建与交互脚本审查与修复

2026-09-05 已修复上轮记录的获取失败复用、零步长停滞和输出历史无限增长问题。

- 默认 xv6 提交集中保存在 `fixtures/xv6-revision`。在线获取失败立即退出；离线模式必须显式开启，并核对仓库地址、请求提交和当前 HEAD。构建记录保存实际提交及镜像 SHA-256，拒绝覆盖已跟踪源码修改。
- 交互程序迁入 `examples/xv6.rs`，启动脚本只负责准备镜像和终端。它调用正式 `Xv6Fixture::build`，不包含测试代码；仅按运行需要检查镜像，关闭加速时无需构建元数据。
- 步长和启动预算必须为正整数。运行批次受剩余预算约束，防止大步长越过启动上限；UART 定期输出并清除历史，输入通道也设有容量上限。
