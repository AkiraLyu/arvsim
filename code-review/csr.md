# CSR 审查与修复

2026-09-05 已修复公共 `Csr::load/store` 接受无效地址时的数组越界。

宿主状态接口保留原有签名：读取未实现或越界地址返回零，写入忽略。它不会创建不存在的 CSR，也不会因 `usize::MAX` 等输入崩溃。

CPU 执行 CSR 指令时仍先检查实现状态、特权级和读写权限；无效访问产生非法指令异常。宿主便利接口的默认返回值不改变客体架构行为。

测试覆盖未实现地址、首个越界地址和 `usize::MAX`；原有权限、别名、PMP 和 Sstc 测试继续运行。接口说明见 [CSR 文档](../docs/repository-status/csr.md)。
