# Virtio 块设备审查与修复

2026-09-05 已修复 DMA 完成信息问题，并新增合法描述符布局的支持。

请求开始前检查全部数据范围、状态字节和 used ring 写入范围。畸形地址不会在检查失败前修改块介质或部分数据；后端中途失败时保留实际完成的连续数据前缀长度。

旧报告把 `used.len` 解释为必须精确等于全部已写字节，这是误读。规范允许少报，但要求已初始化该长度内的连续前缀。若第一个 512 字节数据块完成、后一个失败，即使末尾状态字节已写回，也最多报告前缀 512，不能报告 513。

故障测试按不可读扇区注入错误，记录正式 DMA 接口成功写入的范围，检查错误状态和报告前缀是否全部初始化。不依赖后端调用次数、传输分块大小或错误时精确完成的字节数。复位测试先提交真实读请求产生中断，再检查复位结果，不直接修改设备内部中断字段。

原实现还假定首个描述符完整容纳请求头、末尾独立描述符容纳状态。现在按消息字节顺序解析：请求头可以拆分，也允许请求头与 OUT 数据、IN 数据与状态共用描述符。仍要求设备可读部分位于可写部分之前。

特性协商拒绝未提供的特性。设备提供 `VIRTIO_F_VERSION_1`；规范允许设备拒绝驱动未接受该特性的情况，但并非强制，本实现保留与当前 xv6 驱动的兼容行为。

依据：[Virtio 1.2](https://docs.oasis-open.org/virtio/virtio/v1.2/virtio-v1.2.html) 的 2.7.4、2.7.8.2、5.2.6 和 6.2 节。测试还覆盖介质边界、完整队列索引、复位和中断；能力范围见 [Virtio 文档](../docs/repository-status/virtio.md)。
