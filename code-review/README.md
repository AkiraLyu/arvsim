上轮记录的 11 项发现已逐项处理。Virtio 的原始分析有一处规范误读：`used.len` 可以少报，但报告长度内的连续前缀必须已初始化，不能简单相加已写数据和远端状态字节。本轮同时修复了新确认的 DMA 保留失效、描述符边界和用户态调用捷径问题。

## 代码与测试边界

页表位、页大小和地址转换函数集中在私有 `paging` 模块；DRAM 的加载、清零、CPU 和 DMA 访问共用范围检查。xv6 专用加速集中在 CPU 子模块，镜像验证和平台组装放在 `src/xv6.rs`，交互逻辑放在 `examples/xv6.rs`。

测试保留汇编输入、页表与队列构造、故障注入和断言；不复制实际设备、指令、镜像解析或系统调用实现。故障注入后端只用于触发正式实现的错误分支。

## 测试精简原则

预期来自功能需求和外部约定，优先检查执行结果、可见状态及错误。加速测试经正常单步入口进入，避免无关前置条件使测试提前通过；不使用同一模块的另一条内部路径作为正确性判据。集成层保留程序执行与整机协作，设备细节留在设备模块验证。
